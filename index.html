Maya Studio – Privacy Policy

Last updated: November 11, 2026

Maya Studio is a private tool used only by its owner to publish short fitness videos to the owner's own Facebook Page ("Maya Fitness Coach"), Instagram account (@maya.fitnesscoach.ai) and YouTube channel ("Maya Fitness", @maya.fitnesscoach). "Maya" is an AI-generated character, and this is disclosed on every video. Maya Studio is not offered to the public and no one else can log in to it.

What information we access

Through the Meta Graph API, Maya Studio accesses only the owner's own Facebook Page and linked Instagram professional account, in order to:

  • publish videos (Reels) and their captions;
  • read basic account and Page details (name, ID, username) needed to publish.

Through YouTube API Services, Maya Studio accesses only the owner's own YouTube channel, using the youtube.upload permission, in order to:

  • upload videos (Shorts) with their title, description and tags, marked as containing altered or synthetic content.

Maya Studio does not collect, store, sell or share personal information about other people, followers, viewers or visitors. It does not read private messages or comments, does not read, download or store any YouTube data, and does not use data for advertising.

YouTube API Services

Maya Studio uses YouTube API Services. By using Maya Studio you agree to be bound by the YouTube Terms of Service. Information handled by YouTube is also subject to the Google Privacy Policy.

The Google OAuth token used to upload videos is stored only on the owner's computer. Access can be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions.

How information is stored

Access tokens and the videos being published are stored only on the owner's own computer and are used only to publish content to the owner's accounts. Nothing is shared with third parties.

Data deletion

Maya Studio stores no data about anyone other than its owner. If you believe any of your information has been processed by Maya Studio, or you want it removed, email mayastudioai@gmail.com and it will be deleted within 30 days. The owner can remove Maya Studio's access at any time in Facebook Settings → Business Integrations, and in the Google security settings linked above.

Contact

Questions about this policy: mayastudioai@gmail.com
